# 🎯 Number Flash — Frontend

A fast, interactive memory flash game built with **React**, **Vite**, and **Tailwind CSS**. It connects to a decoupled Express/Supabase backend for authentication and leaderboard syncing.

---

## 🛠️ Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Authentication**: Supabase Auth Client
- **Backend Repository**: [Number Flash Backend GitHub Repository](https://github.com/Arman-Saif/Flash-Memory-Backend)

---

## ⚙️ Environment Configuration (`.env.example`)

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=https://your-supabase-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
VITE_API_URL=Backend Server URl
```

---

## 🚀 Quick Start Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```
